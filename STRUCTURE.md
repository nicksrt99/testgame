# Структура проекта

| Файл | Что делает |
|------|-----------|
| `index.html` | Страница игры: холст `<canvas>` и подключение скриптов |
| `style.css` | Убирает отступы и прокрутку, растягивает холст на весь экран |
| `config.js` | Все настройки игры: числа, цвета, размеры |
| `input.js` | Клавиатура: помнит, какие клавиши сейчас зажаты |
| `player.js` | Всё про игрока: объект `player`, его движение и рисование |
| `main.js` | Основной код игры: игровой цикл, обновление и рисование |
| `CLAUDE.md` | Правила работы над проектом |

## Порядок подключения скриптов

1. `config.js` — настройки должны загрузиться первыми.
2. `input.js` — клавиатура; ей пользуется игрок.
3. `player.js` — объект `player` сразу берёт стартовые значения из `config.js`.
4. `main.js` — использует настройки и вызывает функции игрока.

## Как работает игра

Игровой цикл: каждый кадр (столько раз в секунду, сколько обновляется экран)
браузер вызывает `gameLoop`, она считает `deltaTime`, делает `update` → `draw` и снова
записывает себя на следующий кадр через `requestAnimationFrame`.

Delta time — сколько секунд прошло с прошлого кадра. Всё движение считается как
`скорость (в секунду) × deltaTime`, поэтому скорость одинакова на мониторах с любой частотой.
Цепочка передачи: `gameLoop` → `update(currentTime, deltaTime)` → `updatePlayer(deltaTime)`.

Управление: `input.js` при нажатии/отпускании клавиши записывает это в `pressedKeys`.
Каждый кадр `updatePlayer()` спрашивает `isKeyPressed(...)` и сдвигает игрока.

## Главные функции

### input.js
- `pressedKeys` — объект: какие клавиши зажаты (`{ KeyW: true, ArrowLeft: false }`). Ключ — `event.code`, физическое место клавиши (работает при любой раскладке).
- `handleKeyDown(event)` / `handleKeyUp(event)` — браузер вызывает их при нажатии / отпускании клавиши.
- `isKeyPressed(code)` — возвращает `true`, если клавиша сейчас зажата.

### player.js
- `player` — объект игрока: `x`, `y` (левый верхний угол), `size`, `color`, `speed`.
- `drawPlayer()` — рисует игрока квадратом. Вызывается из `draw()` после фона и до надписей.
- `updatePlayer(deltaTime)` — двигает игрока стрелками или WASD. Сначала по клавишам находит направление `moveX`, `moveY` (−1, 0 или 1), по диагонали делит оба на √2 (чтобы скорость была одинаковой), потом сдвигает игрока на `направление × player.speed × deltaTime`. Вызывается из `update()`.

### main.js
- `resizeCanvas()` — подгоняет размер холста под окно браузера. Вызывается при загрузке и при изменении размера окна.
- `update(currentTime, deltaTime)` — обновляет состояние игры: считает кадры и FPS, двигает игрока.
- `draw()` — рисует слоями: фон (стирает прошлый кадр) → игрок → отладка (кадр, FPS, координаты игрока, округлённые через `Math.round`).
- `gameLoop(currentTime)` — игровой цикл: считает `deltaTime` (не больше `MAX_DELTA_TIME`) → `update` → `draw` → `requestAnimationFrame(gameLoop)`. `currentTime` присылает браузер (миллисекунды с открытия страницы).

### Переменные main.js
- `frameCount` — сколько кадров нарисовано всего (временно, для проверки).
- `fps` — сколько кадров было за последнюю секунду (показывается на экране).
- `framesThisSecond` — счётчик кадров текущей секунды.
- `lastFpsTime` — время начала текущей секунды (мс).
- `lastFrameTime` — время прошлого кадра (мс), нужно для подсчёта `deltaTime`.

## Настройки (config.js)
- `BACKGROUND_COLOR` — цвет фона холста.
- `DEBUG_TEXT_COLOR`, `DEBUG_TEXT_FONT` — цвет и шрифт отладочной надписи.
- `DEBUG_TEXT_X`, `DEBUG_TEXT_Y` — где начинается надпись (Y — по нижней линии букв).
- `DEBUG_TEXT_LINE_HEIGHT` — расстояние между строками надписи.
- `PLAYER_SIZE`, `PLAYER_COLOR` — размер и цвет игрока.
- `PLAYER_START_X`, `PLAYER_START_Y` — где игрок появляется.
- `PLAYER_SPEED` — скорость игрока в точках за секунду.
- `MAX_DELTA_TIME` — самый большой `deltaTime` (в секундах); защита от прыжка после свёрнутой вкладки.
